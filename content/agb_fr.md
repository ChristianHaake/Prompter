# Conditions d’utilisation (AGB)

**Projet soumis à l’examen de l’exploitant. Cette version n’a pas encore été approuvée.**

## Offre

Prompter est une application gratuite, accessible dans un navigateur, permettant d’écrire et de présenter des scripts. Aucun compte utilisateur n’est nécessaire.

## Contenus personnels

Les scripts saisis restent dans le navigateur. Le brouillon actuel y est enregistré localement. Les fichiers de projet et les fichiers CSV ne sont créés qu’à la suite d’un export déclenché par l’utilisateur. Lors de l’ouverture d’un projet, le brouillon précédent peut être remplacé ; l’application demande une confirmation au préalable.

Les utilisateurs décident eux-mêmes quels contenus saisir, exporter ou partager. Il est recommandé de ne pas utiliser de données personnelles sensibles dans les scripts utilisés en classe.

## Disponibilité et contact

L’application nécessite un navigateur récent. Certaines fonctions du navigateur, comme le plein écran ou Wake Lock, peuvent ne pas être disponibles. Les questions et signalements d’erreurs peuvent être envoyés à [apps@haak3.de](mailto:apps@haak3.de) ; les contenus de scripts privés ne doivent pas être joints.
