# Condiciones de uso (AGB)

**Borrador para revisión del operador. Esta versión aún no ha sido aprobada.**

## Servicio

Prompter es una aplicación basada en el navegador, de uso gratuito, para escribir y presentar guiones. No hay cuentas de usuario.

## Contenido propio

Los guiones introducidos permanecen en el navegador. El borrador actual se guarda allí localmente. Los archivos de proyecto y los archivos CSV solo se generan cuando el usuario inicia una exportación. Al abrir un proyecto, se puede reemplazar el borrador anterior; la aplicación lo confirma antes.

Los usuarios deciden por sí mismos qué contenido introducir, exportar o compartir. No se deben incluir datos personales sensibles en los guiones para clase.

## Disponibilidad y contacto

La aplicación requiere un navegador actualizado. Es posible que algunas funciones del navegador, como la pantalla completa o Wake Lock, no estén disponibles. Se pueden enviar preguntas e informes de errores a [apps@haak3.de](mailto:apps@haak3.de); no se debe adjuntar contenido privado de los guiones.
