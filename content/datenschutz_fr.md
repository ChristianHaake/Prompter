## 5. Traitement local des données saisies

Prompter traite en principe localement dans le navigateur les contenus saisis par
l’utilisateur.

Les contenus saisis ne sont ni transmis à l’exploitant ni enregistrés par lui.
Le brouillon et l’historique des présentations restent enregistrés dans le même
navigateur jusqu’à leur suppression dans l’application ou dans les données du site.

Le brouillon actuel est enregistré dans le navigateur sous la clé `localStorage`
`prompter_project_v1`. Cet enregistrement sert à restaurer localement le brouillon
dans le même navigateur. Les utilisateurs peuvent supprimer ces données en
utilisant « Nouveau » dans l’application ou en supprimant les données du site web
dans le navigateur.

L’historique des présentations est enregistré séparément sous la clé
`localStorage` `prompter_pitch_history_v1`. Il contient les dates et heures, les
durées cibles, les durées réelles, le nombre de mots ainsi que le statut « terminé »
ou « interrompu ». Ces données restent dans le navigateur ; elles peuvent être
supprimées dans l’éditeur et exportées sous forme de fichier CSV local.

Les fichiers `.prompter` exportés sont générés localement par le navigateur et se
trouvent ensuite en dehors de l’application, dans le système de fichiers de
l’utilisateur.
